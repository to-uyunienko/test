# サブスク&ローン家計管理

毎月/毎年のサブスクリプション費用と、ローン・借入の返済を一括で管理するブラウザ完結型のWebアプリです。ビルドやサーバーは不要で、`index.html` を開くだけで動作し、データはブラウザの `localStorage` に保存されます。

## 使い方

`index.html` をブラウザで開くだけで利用できます。ローカルで確認する場合は簡易サーバーを立てても構いません。

```bash
python3 -m http.server 8000
# http://localhost:8000 を開く
```

## 主な機能

- **サブスクリプション管理**: サービス名・金額・周期(月次/年次)・次回請求日・カテゴリを登録し、月換算コストを自動計算
- **ローン・借入の返済管理**: 借入元金・年利・返済期間・借入開始日から、元利均等返済の月次返済額と残債(概算)、完済予定日を自動計算
- **統合ダッシュボード**: 今月/年間の支出合計、サブスクとローンの内訳、カテゴリ別の内訳、今後30日以内の支払い予定を一覧表示

## データについて

すべてのデータはブラウザの `localStorage` にのみ保存され、外部サーバーへの送信は行いません。ブラウザやプロファイルを変えるとデータは引き継がれません。

## 構成

```
index.html       画面全体
css/style.css    スタイル
js/storage.js    データ永続化(localStorage)
js/subscriptions.js  サブスクのCRUDと計算
js/loans.js      ローンのCRUDと元利均等返済の計算
js/charts.js     依存ライブラリなしのSVGチャート(ドーナツ/バー)
js/dashboard.js  ダッシュボードの集計・描画
js/app.js        タブ切替と初期化
```
